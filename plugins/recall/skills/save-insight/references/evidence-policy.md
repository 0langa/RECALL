# Evidence Policy

Save facts that can change future work: accepted decisions, verified commands,
requirements, diagnosed failures, stable architecture, open risks, and explicit
standing preferences.

Do not save drafts, routine read-only tool output, transient task instructions,
unverified model guesses, secrets, or facts already represented by current memory.

File-backed claims should include a project-relative source path. Mutually exclusive
claims should include a stable claim key and normalized value. Preference evidence
must identify an explicit declaration or meaningful user decision.
